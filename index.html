I'm an AI Platform & Developer Tools Engineer who builds production systems, not demos. I specialize in the intersection of agentic AI, developer tooling, and distributed FinTech infrastructure — systems where architecture, reliability, and scale actually matter.

I'm the Founder & CEO of Kryex Labs, building full-time for regulated enterprises. Our first product, Kryex Code, is a self-hosted coding agent designed so the agent never holds credentials: database and MCP calls pass through a customer-side server that checks the user's access before execution.

As founding engineer, I built the platform end to end: desktop client, self-hosted control plane, credential vault, policy engine, and customer-owned audit trail. Kryex Code runs in a VPC or fully air-gapped, supports any model, and is shipped on Mac and Windows. Download Kryex Code ↗
